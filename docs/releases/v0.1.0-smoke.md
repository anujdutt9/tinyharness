## Scope and limitations

- Live calls exercised a strong cloud model plus a smaller model in a background role.
- A local OpenAI-compatible endpoint and a local model acting as the lead agent were not tested.
- Scripted tests cover provider adapters, but this run was not a live cross-provider benchmark.
- The run validates release mechanics and trace invariants; it does not establish statistical
  task-success, latency or cost performance.

## Post-hardening validation

The final containment behavior was validated after the main smoke run:

- A live cloud model first tried a harmless write outside the permitted temporary root.
  The sandbox denied it, returned structured recovery guidance, and the model retried
  successfully in the private per-session temporary directory without weakening containment.
- A real Playwright install was denied when it reached an unapproved download host. The same
  sandboxed command succeeded after granting that exact host for the call, stored Chromium's
  headless shell in the private browser cache, and then rendered a local HTML page offline.
- A live model proposed an explicit package installation. The harness produced a distinct
  software-acquisition request, the test policy denied it, and the model did not execute or
  retry the command. Automated tests separately verify exact-command session approval and
  a second, independent decision for any newly required network destination.
- Automated tests verify that an approved bare Python install creates a project `.venv`
  when no environment is active, reuses a writable active virtualenv or Conda environment,
  and does not modify the launcher environment when it sits outside the sandbox.
- The complete automated suite passed with 1011 tests and 5 skips; the opt-in terminal suite
  passed all 5 tests. Ruff lint and formatting plus mypy also passed.
- The wheel and source archive rebuilt successfully. A clean environment installed the wheel,
  and both the CLI and SDK reported version `0.1.0`.

The macOS Seatbelt path and exact-host flow were exercised end to end. The optional Sandbox
Runtime translation is covered by automated tests but was not exercised on a Windows or Linux
host during this release check.

- The sandbox host allowlist constrains network destinations; opaque HTTPS tunnels do not
  provide request-level data-loss prevention for an otherwise allowed host.
- The report contains no prompts, responses, absolute paths, session identifiers or credentials.
