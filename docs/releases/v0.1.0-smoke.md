## Usage observation

This is a single-run baseline observation, not a performance, quality or cost claim. It
must not be compared with another model, provider or harness configuration without paired
tasks, pinned versions and repeated runs.

## Scope and limitations

- Live calls exercised a strong cloud model plus a smaller model in a background role.
- A local OpenAI-compatible endpoint and a local model acting as the lead agent were not tested.
- Scripted tests cover provider adapters, but this run was not a live cross-provider benchmark.
- The run validates release mechanics and trace invariants; it does not establish statistical
  task-success, latency or cost performance.

## Post-hardening validation

The final containment behavior was validated after the main smoke run:

- Windows path normalization, output-limited tool-batch rejection, shell acquisition
  parsing, and PEP 723 target resolution have dedicated regressions. The current full suite
  passed 1,079 tests with 9 skips; all 6 opt-in terminal tests passed; Ruff, formatting,
  mypy, and the wheel/source build passed.
- Windows fallback file operations now hold no-delete directory handles and refuse symlinks
  and reparse points after approval. Forced-fallback regressions cover swapped directories and
  files; the native hosted Windows matrix passed on Python 3.11, 3.12 and 3.13.
- Acquisition regressions now cover shell conditionals, `env -u`, `env -S`, versioned `pip`,
  and absolute Python launchers. Only the parsed installation executable is rebound to the
  writable environment named in its approval; earlier matching arguments and the fresh-venv
  bootstrap interpreter remain unchanged. Environment-path tests run cross-platform.
- Once outside content is present, an outbound-capable Bash call asks even when its sandbox
  destination is already allowlisted. A sandbox configured with no outbound destinations keeps
  local commands routine.
- A live `gpt-6.1-sol` run proposed `python -I -m pip install` as instructed. The
  non-interactive approval boundary denied it before execution; the model reported the
  denial and did not retry, alter the command, or install another package (4.1k context,
  107 output tokens, approximately $0.01).

- A live cloud model first tried a harmless write outside the permitted temporary root.
  The sandbox denied it, returned structured recovery guidance, and the model retried
  successfully in the private per-session temporary directory without weakening containment.
- A real Playwright install was denied when it reached an unapproved download host. The same
  sandboxed command succeeded after granting that exact host for the call, stored Chromium's
  headless shell in the private browser cache, and then rendered a local HTML page offline.
- A live model proposed an explicit package installation. The harness produced a distinct
  software-acquisition request, the test policy denied it, and the model did not execute or
  retry the command. Automated tests separately verify exact-command session approval and
  a second, independent decision for any newly required network destination.
- Automated tests verify that an approved bare Python install creates a project `.venv`
  when no environment is active, reuses a writable active virtualenv or Conda environment,
  and does not modify the launcher environment when it sits outside the sandbox.
- Regression tests verify that a PEP 723 script remains acquisition-gated after a shell
  directory change, a resumed skill restores its required extensions, legacy saved todos gain
  stable IDs, and memory audit records switch to the new session after `/clear`.
- The final local automated suite passed with 1,079 tests and 9 skips; the opt-in terminal
  suite passed all 6 tests. Ruff lint and formatting plus mypy also passed. The hosted
  minimum-dependency job and full Python 3.11-3.13 platform matrix passed for the code candidate.
- The wheel and source archive rebuilt successfully. A clean environment installed the wheel,
  and both the CLI and SDK reported version `0.1.0`.
- A live configured cloud model read a synthetic non-sensitive Markdown file, accurately
  summarized it, and presented it through the core Open tool as a typed clickable artifact
  without launching a host application. The check used 5.5k context tokens, 220 output tokens,
  and reported approximately $0.02.

The macOS Seatbelt path and exact-host flow were exercised end to end. Hosted CI exercised
Windows across Python 3.11-3.13 and the optional Sandbox Runtime on Linux; all passed for the
code candidate. The latest approval and outbound-consent changes have not yet been rerun against
a live model.

- The sandbox host allowlist constrains network destinations; opaque HTTPS tunnels do not
  provide request-level data-loss prevention for an otherwise allowed host.
- The report contains no prompts, responses, absolute paths, session identifiers or credentials.
