What it is

The loop that turns an LLM into an agent

  • It reads, searches and edits your code, runs commands in a sandbox, asks before it changes things, and keeps long sessions inside the context window.
  • No framework underneath — it's about 9,000 lines of commented Python, built to be read, not just imported.
  • Works two ways: as a CLI you run in your terminal, and as a Python SDK (Session, typed event stream) for building your own agent.

tinyharness08 / 12
agent/runaway.py · agent/compaction.py

Built for mid-size models too, not just the best ones

Cut-off & empty replies
Recovered automatically — a reply cut off at the output limit never gets run as a tool call.
Tool calls written as text
Small models sometimes write a call instead of emitting one; llm/textcalls.py repairs it.
Malformed arguments
Arguments are validated and repaired before a tool ever runs.
Context that stays within budget
Oversized messages are capped, old tool output is stubbed, then summarized — without rebuilding the prompt cache every turn.
